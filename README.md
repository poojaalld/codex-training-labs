# codex-training-labs
Codex hands-on labs for developers.

Each lab is meant to incrementally teach the Codex workflow by focusing on a single skill (login systems, refactoring, PR generation, etc.).

## Labs
- Lab 1: Login System (FastAPI starter with JWT authentication)
- Lab 2: Refactor legacy code
- Lab 3: Bug fixing
- Lab 4: PR generation
- Lab 5: Multi-agent coordination
- Lab 6: Reviewer mode
- Lab 7: Prompt engineering
- Lab 8: Spec-to-code translation
- Lab 9: Capstone project

## Working with this repo
1. Clone and create a feature branch for the lab you are working on.
2. Install dependencies (pip install -r requirements.txt) and run local tests from each lab directory.
3. Keep datasets, instructor guides, and fixtures in their respective folders so every lab can be shipped cleanly.
4. When you are done, open a PR with the lab-specific changes for review.
